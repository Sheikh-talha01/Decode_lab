To run the project in this folder:

1. Copy `.env.example` to `.env` and set `OPENAI_API_KEY`.
2. Install dependencies: `pip install -r requirements.txt`.
3. Run single example: `python run.py --product Shoe --name "Acme" --tone witty --platform linkedin`.
4. Or run the API with `docker compose up --build` and visit `http://localhost:8000/docs`.
